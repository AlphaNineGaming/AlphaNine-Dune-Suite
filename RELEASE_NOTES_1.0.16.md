# AlphaNine Dune Suite 1.0.16

Market Bot install result hotfix.

## What's Changed

- Fixed the Market Bot install button showing a follow-up refresh error as if the install itself failed.
- Suite now keeps the successful install message visible and reports post-install refresh/log failures separately.

## Notes

- This update does not change, delete, or recreate market listings.
- If the install succeeds but refresh still fails, use `Refresh Bot` after a few seconds or check the Market Bot logs.
