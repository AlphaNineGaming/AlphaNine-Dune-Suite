# AlphaNine Dune Suite 1.0.52

## Schematic catalog organization

- Separates schematic inventory items, research unlocks, and recipe-only unlocks.
- Preserves schematic source grades instead of forcing manager entries to Unique.
- Groups catalog results by category and tier with sticky section headings.
- Adds name and tier sorting to Give Item and Item Database.
- Adds clear result counts and incremental Load More controls for large catalogs.
- Disambiguates same-name tier and vehicle schematic variants.
- Deduplicates item template IDs case-insensitively across bundled catalog sources.
