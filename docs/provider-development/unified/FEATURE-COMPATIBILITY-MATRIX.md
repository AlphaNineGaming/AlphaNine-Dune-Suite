# Complete feature compatibility audit — Suite 1.3.24

This matrix groups every discovered server/Manager route literal and prefix, all 27 embedded view sections, 11 desktop IPC channels and the shared library surface. The machine-readable companion records 276 file/route entries, 303 handler predicates and exact source line references/hashes. Prefixes and runtime-generated suffixes are included as route families; reachability and method semantics must be read from the predicates. Static inventory is not proof of live compatibility. Some historical source remains behind disabled gates.

HV = Hyper-V; SSH = remote transport; FS = filesystem/paths; K8S = Kubernetes/battlegroup CRDs; PG = PostgreSQL/schema; WIN = Windows/desktop tooling; HTTP = network/admin protocol; AMQP = RabbitMQ/receiver.

**Hyper-V:** existing implementations and per-action safeguards retained, with regression/static evidence; no fresh hardware verification. **Docker, Proxmox and managed-hosting server providers:** Unsupported/planned for every hosting-dependent operation. Docker workload inspection through Remote Linux is a separate runtime scope and does not implement the Docker server provider. **Remote Linux:** only the explicitly adapted reads below are Experimental; all other feature operations are Unsupported. Hosting-independent business logic is reusable but does not automatically grant a capability. No new feature is Verified.

## UI and routing coverage

Embedded views: dashboard, server-health, operations, live-map, players, blueprints, give, repair, market, legacy-market, env, admin, cleanup, landsraad, progression, server, scheduler, database, logs, management, usergame-settings, web-portal, item-database, database-explorer, codex, diagnostics, settings. These retain their existing pages/navigation. Unsupported views display an availability reason and disabled controls; they do not invoke their legacy loaders. The hidden legacy market, admin and discontinued migration source is not newly enabled.

Desktop IPC: blueprint-designer-status, blueprint-designer-open, blueprint-designer-theme, choose-ssh-key, choose-server-install-folder, choose-game-folder, choose-database-backup-folder, choose-database-backup-file, open-path, open-battlegroup-batch, self-update-install. Local document Designer and file-selection dialogs are app-level capabilities with existing origin checks; their presence does not authorize remote game operations. Nonlegacy batch/script and arbitrary path launching are refused in the main process.

All unregistered nonlegacy backend routes fail closed, including operations that historically mutate via GET. Adapted routes use exact method/path matching. Client controls are convenience only; fresh evidence, target binding and backend admission are authoritative. See UNIFIED-ARCHITECTURE.md for the adapter contracts, limitations and mutation design.
