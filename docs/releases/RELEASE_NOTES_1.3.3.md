# AlphaNine Dune Suite v1.3.3

## Visual improvements

- Improved spacing, typography, sidebar density, and panel layouts.
- Improved responsive sizing and keyboard focus visibility.
- Refined Server Manager editor and output layouts.
- Updated the Discord community link to https://discord.gg/kutj6MyR2.

## Compatibility

Application behavior is preserved from 1.3.2. This release applies the approved visual-only polish; it does not include the earlier functional review changes. The bundled Market Bot runtime remains 1.0.102.

Documentation is organized under `docs/`, including the release archive.

## Upgrade

Install the 1.3.3 installer over your existing installation.
